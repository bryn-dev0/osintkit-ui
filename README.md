# OsintKit

Prototipo de baja fidelidad de una plataforma web de inteligencia de fuentes
abiertas (OSINT) para analistas de ciberseguridad. Permite buscar usuarios,
auditar dominios e IP, extraer metadatos y generar reportes.

## Tecnologías

HTML5, CSS3 y JavaScript puro. Sin frameworks ni librerías.

## Cómo ejecutarlo

1. Clona el repositorio:
   `git clone https://github.com/bryn-dev0/osintkit-ui.git`
2. Abre `prototipo/login.html` en el navegador.

No requiere instalación ni servidor.

## Estructura

- `AGENTS.md`: reglas del proyecto para el agente de codificación.
- `docs/`: historias de usuario, requisitos y componentes.
- `prototipo/`: pantallas HTML y `styles.css`.
