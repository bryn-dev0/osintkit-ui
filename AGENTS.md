# Proyecto OsintKit
Plataforma web de inteligencia de fuentes abiertas (OSINT) para analistas de ciberseguridad.
Permite buscar usuarios, auditar dominios/IP, extraer metadatos y generar reportes.

## Reglas
- Solo HTML5, CSS3 y JavaScript. No usar frameworks ni librerías (React, Tailwind, Bootstrap, etc.).
- Toda la interfaz en español.
- HTML semántico: usar header, nav, main, section, form, table, label.
- Cada campo de formulario debe tener su <label> asociado.
- Un solo archivo styles.css con variables de color en :root.
- Toda pantalla parte de plantilla.html y usa solo clases de styles.css.
- Diseño responsivo: debe verse bien en celular (mínimo desde 360px).
- Antes de crear o modificar archivos, muestra el plan y espera mi confirmación.
- No inventar requisitos que no estén en docs/historias.md o docs/requisitos.md.
- Usar solo datos ficticios (nombres, correos, etc.).
