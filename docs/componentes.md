# Componentes reutilizables — OsintKit (prototipo)

Listado de componentes reutilizables detectados en `prototipo/`.  
Pantallas referenciadas: login, registro, recuperar, dashboard, busqueda, auditoria, metadatos, historial, reportes, perfil, 404, plantilla.

| Componente                | Etiqueta HTML          | Clase CSS                            | Pantallas donde aparece                                                                                 |
| ------------------------- | ---------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| Encabezado                | `<header>`             | `encabezado`                         | todas                                                                                                   |
| Contenedor del encabezado | `<div>`                | `contenedor encabezado__inner`       | todas                                                                                                   |
| Marca / Logo              | `<a>`                  | `marca`                              | todas                                                                                                   |
| Navegación / Menú         | `<nav>`                | `navegacion`                         | todas (enlaces varían por pantalla)                                                                     |
| Contenedor                | `<div>`                | `contenedor`                         | todas                                                                                                   |
| Contenido principal       | `<main>`               | `contenedor principal`               | todas                                                                                                   |
| Sección                   | `<section>`            | `seccion`                            | todas                                                                                                   |
| Formulario                | `<form>`               | `formulario`                         | login, registro, recuperar, busqueda, auditoria, metadatos, historial, reportes, perfil                 |
| Campo de formulario       | `<div>` / `<fieldset>` | `campo`                              | login, registro, recuperar, busqueda, auditoria, metadatos, historial, reportes, perfil                 |
| Botón                     | `<button>` / `<a>`     | `boton`                              | login, registro, recuperar, dashboard, busqueda, auditoria, metadatos, historial, reportes, perfil, 404 |
| Botón secundario          | `<a>` / `<button>`     | `boton boton-secundario`             | login, registro, recuperar, auditoria, metadatos, reportes, 404                                         |
| Grupo de botones          | `<div>`                | `boton-grupo`                        | login, registro, recuperar, busqueda, auditoria, metadatos, historial, reportes, perfil, 404            |
| Tarjeta                   | `<article>`            | `tarjeta`                            | dashboard, busqueda                                                                                     |
| Cuadrícula                | `<section>`            | `grid` / `grid-3`                    | dashboard                                                                                               |
| Tabla                     | `<table>`              | `tabla`                              | auditoria, metadatos, historial, perfil                                                                 |
| Insignia (badge)          | `<span>`               | `badge`                              | busqueda                                                                                                |
| Alerta                    | `<div>`                | `alerta`                             | login, registro, recuperar, auditoria, metadatos, historial, reportes, perfil                           |
| Indicador de carga        | `<p>`                  | `cargando`                           | busqueda, auditoria, metadatos                                                                          |

| Texto pequeño             | `<small>`              | (sin clase propia, dentro de `.pie`) | todas                                                                                                   |
